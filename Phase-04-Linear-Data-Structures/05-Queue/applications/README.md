# Queue Applications

The most important queue applications are covered in other modules:

| Application | Where It Lives |
|-------------|----------------|
| **BFS on graphs / trees** | Phase 05 Recursion (iterative) and Phase 08 Graphs |
| **Level-order tree traversal** | Phase 07 Trees |
| **Shortest path (unweighted)** | Phase 08 Graphs |
| **Producer/consumer concurrency** | Beyond DSA scope; see Python's `queue.Queue` |
| **Priority scheduling** | Phase 07 Heaps |
| **Sliding-window maximum (with deque)** | Phase 04 / 06-Deque, and Phase-02 / 02 / 09-Monotonic-Stack |

The two problems in this module (`../problems/generate-binary.py` and
`../problems/stack-using-queues.py`) stand on their own as
queue-specific exercises.

When you reach the graph and tree modules, the queue you built here
will be recognized as a specific tool applied to a broader algorithmic
pattern (BFS).
