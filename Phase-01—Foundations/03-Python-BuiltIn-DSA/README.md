# Python Built-in Data Structures

This section dives deep into Python's built-in data structures—the fundamental tools you'll use every day in problem solving and algorithm implementation. Having already learned about time and space complexity, you will now analyze each structure's performance characteristics and practice using them in coding problems.

---

## 📚 What's Inside

| Folder              | Description                                                                                     |
|---------------------|-------------------------------------------------------------------------------------------------|
| **01-List**         | Dynamic arrays: theory, operations, time complexity, and practice problems (easy/medium/hard). |
| **02-Tuple**        | Immutable sequences: theory, operations, time complexity, and problems.                        |
| **03-Dictionary**   | Hash tables: theory, operations, time complexity, and problems.                                |
| **04-Set**          | Hash sets: theory, operations, time complexity, and problems.                                  |
| **05-String**       | String methods and patterns: theory, operations, time complexity, and problems.                |
| **06-Collections-Module** | Advanced containers: `deque`, `Counter`, `defaultdict`, etc., with time complexity and problems. |

Each subfolder follows a consistent structure:

- `theory.md` – Conceptual explanation, use cases, and internal workings.
- `operations.py` – Code examples showing common operations.
- `time-complexity.md` – Big O analysis for each operation (now meaningful after Phase-02!).
- `problems/` – Curated problems (with difficulty levels) to reinforce learning.

---

## 🎯 Learning Objectives

By the end of this section, you will be able to:

- Choose the right built-in data structure for a given problem.
- Predict the time and space complexity of operations on lists, tuples, dictionaries, sets, strings, and collections.
- Implement efficient solutions using Python's built‑in tools.
- Solve a variety of coding problems that leverage these structures.

---

## 🧭 How to Use This Section

1. **Start with the theory** – Read the `theory.md` for each data structure to understand its purpose and how it works under the hood.
2. **Explore operations** – Run and modify the `operations.py` scripts to see the syntax and behavior firsthand.
3. **Study time complexity** – Refer to `time-complexity.md` to internalize the cost of each operation.
4. **Practice** – Tackle the problems in `problems/`, starting from easy and moving to harder ones. Solutions are provided (in `solutions.md` where applicable) so you can check your work.
5. **Consolidate** – Use the **06-Collections-Module** to learn about specialized containers that often simplify complex tasks.
